# 构建说明

## 环境

| 项目 | 固定版本 |
|---|---|
| JDK | 17 |
| Gradle Wrapper | 8.13（发行ZIP校验值已固定） |
| Android Gradle Plugin | 8.13.2 |
| Kotlin / Compose插件 | 2.2.21 |
| KSP | 2.2.21-2.0.4 |
| Android SDK | compile / target 36，min 26 |
| Room | 2.8.4 |

用Android Studio打开项目，安装Android SDK36并按官方提示接受SDK许可。在项目本地设置SDK路径（`local.properties`，不可提交），或配置本机 `ANDROID_HOME`；为本次命令指定JDK17即可，不要求全局安装工具。

Windows建议使用不含中文或空格的克隆路径，例如 `C:/dev/fitness-diary`，避免部分Java/Gradle测试进程的路径编码问题。不要关闭Android路径检查来掩盖问题。

## 编译

Windows PowerShell：

```powershell
.\gradlew.bat assembleDebug --no-daemon
```

Linux / macOS：

```sh
./gradlew assembleDebug --no-daemon
```

输出为 `app/build/outputs/apk/debug/app-debug.apk`。首次运行需要下载Gradle和Maven依赖；依赖完整缓存后才可尝试 `--offline`。仓库包含标准Gradle Wrapper，不需要预装全局Gradle。

## 必要验证

内存有限时，分两个Gradle进程编译测试与执行测试，避免编译器和Native图形测试占用叠加。以下使用PowerShell；其他系统将 `gradlew.bat` 换为 `./gradlew`。

```powershell
.\gradlew.bat compileReleaseUnitTestKotlin --no-daemon
.\gradlew.bat testReleaseUnitTest '-Dorg.gradle.jvmargs=-Xmx512m -XX:+UseSerialGC -XX:ActiveProcessorCount=2 -Dfile.encoding=UTF-8' --no-daemon
.\gradlew.bat lintRelease --no-daemon
```

测试报告在 `app/build/reports/tests/testReleaseUnitTest/`，lint报告在 `app/build/reports/lint-results-release.html`。界面测试产生的示例预览在 `app/build/ui-preview/`。不要跳过失败测试或注释掉报错。

## 正式包与签名

`assembleRelease` 在缺少签名配置时输出未签名APK。原维护者的签名密钥、口令和本机配置不随开源仓库提供，无法从公开源码恢复。自行分发时应创建并妥善保管自己的签名；本仓库不会替你创建或上传私钥。

现有构建逻辑可从本地 `.private/signing.properties` 读取 `storePassword` 与 `keyPassword`，使用同目录 `fitness-diary.p12`、别名 `fitness-diary`。也可用 `FITNESS_SOURCE_ROOT` 指向仓库外的私有配置根目录，确保该根目录下有 `.private`。这些路径已在忽略规则中，但仍应在提交前检查，不能将密钥或口令提交到任何公开历史。

自签名包与本项目正式包签名不同，不能覆盖升级。开发调试可在本地改用不同的 `applicationId`，与正式版并存；应用标识变更产生独立数据空间，须自行导出和恢复备份。

正式1.2.0标识为 `cn.wangguanwen.fitnessdiary`，`versionCode=3`。后续正式升级沿用原签名并递增versionCode。修改数据库schema或备份格式须先设计保留数据的兼容方案。
