# 使用说明

## 安装与升级

从本仓库Releases下载 `fitness-diary.apk`，在手机中打开安装。Android可能要求允许当前浏览器或文件管理器安装未知来源应用，按系统提示操作即可。Android最低版本为8.0；一加12 / ColorOS16的真机验收仍待完成。

正式1.2.0沿用1.0.0和1.1.0的应用标识与签名，可覆盖升级。升级前请先导出完整备份。自行编译的调试包不能覆盖正式包。

冷启动时会播放约3秒的手绘开场。轻触画面或按返回可立即进入趋势页。从后台回来会继续原界面，系统关闭动画时直接进入。

## 记录与历史日期

1. 进入日记页，新增记录。
2. 点击日期打开日历，选择今天或之前的日期，即可补记。每天最多一条；已存在的日期应编辑原记录。
3. 输入体重、感想，或添加照片，至少完成一项。
4. 保存后在日记页找到对应日期，点击编辑可补充或更正；删除需确认。

只删除体重时，清空体重框并保留感想或照片后保存；只删除照片时在编辑页移除对应照片后保存。需要清空整天记录时使用删除。未保存的编辑内容离开时有提示。

体重单位为kg，支持最多两位小数。没有体重的日期仍可保存感想和照片，但不会成为图表的数据点。

## 查看趋势与照片

趋势页支持7/30/90天和全部记录。横轴依据真实日期间隔，圆点是实际称重记录，连接曲线只帮助观察变化。点击图表查看日期和两位小数的体重。没有记录显示提示，一条记录显示单点，两条记录直连。

在记录中点击照片进入查看器，可左右翻看。照片以原有颜色显示；素描效果只用于界面背景。删除应用内副本不删除系统相册原图。

## 备份与恢复

设置页导出完整备份，通过系统文件选择器保存ZIP。备份包含所有体重、文字和照片，建议另存到手机以外的位置。软件没有账号同步或自动云备份，卸载、清除数据或换机前必须手动导出。

恢复时选择完整ZIP，应用先验证版本、内容、大小、照片与校验值，再要求确认。恢复是**完整替换**，不与现有记录合并；先导出现有数据再恢复另一份备份。不要手工修改ZIP内部文件。

每个安装者的数据相互独立，分享APK不会分享你的记录。备份ZIP本身未加密，可能包含私密照片，请保存在你信任的位置，勿提交到GitHub。
