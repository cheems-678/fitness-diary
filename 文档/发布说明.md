# 发布说明

正式安装包在GitHub Releases中提供，仓库只保存源码和文档。当前版本1.2.0 / versionCode3，发布标签为 `v1.2.0`。维护者私钥与口令始终留在私有环境。

## 维护者发布流程

1. 先更新版本与CHANGELOG；保持正式版应用标识和签名连续。数据库、备份格式升级须另行准备兼容方案。
2. 运行必要构建、测试与lint；确认公开源码和构建输入一致，记录测试与真机验收范围。
3. 检查暂存区和提交历史，排除私钥、口令、个人照片、数据库、备份、本机配置与工具缓存；核实第三方素材授权。
4. 将对应源码提交到公开仓库，标签指向同一提交。创建Release时写清用户可见变化、Android最低版本、签名兼容性及已知验证限制。
5. 正式APK统一上传为 `fitness-diary.apk`，同时上传 `SHA256SUMS.txt` 和对应版本源码ZIP。源码ZIP从公开提交生成。
6. 对照远程提交、标签、Release资源大小与SHA-256；验证最新APK固定入口及最新Release JSON，再宣布下载上线。保留旧Release及旧安装包。

本仓库没有自动发布CI，也不保存仓库写入凭据。提交或推送源码不会自动将APK上传到Releases。
